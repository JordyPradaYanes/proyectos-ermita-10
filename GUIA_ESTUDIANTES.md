# 🚀 ¡Bienvenido a tu Laboratorio de Código! 🚀

¡Hola, futuro programador! Este proyecto es **tu laboratorio**. Aquí vas a aprender a cambiar las reglas del juego modificando el código.

Hemos preparado unas **"Zonas de Hackeo"** especiales para ti. Estas son partes del código donde puedes cambiar números, colores y palabras para ver qué pasa. ¡No tengas miedo de romper nada, siempre puedes volver a como estaba antes!

## 🧪 ¿Cómo empezar a hackear?

Cada módulo de este proyecto (como la tabla periódica, la gravedad, o el teorema de Pitágoras) tiene sus propios archivos. Vas a encontrar tres tipos de archivos:

1.  **`.html`**: Es el esqueleto. Aquí están los botones y textos.
2.  **`.css`**: Es la ropa y los colores. ¡Aquí puedes poner todo a tu estilo!
3.  **`.js`**: Es el cerebro. Aquí está la magia y las matemáticas.

---

## 🎯 Tus Misiones (Zonas de Hackeo)

### Misión 1: ¡Cambia la gravedad! 🌍
**Archivo a buscar:** `modules/gravedad/gravedad.js`

Abre ese archivo y busca la variable de la gravedad (al principio del archivo).
```javascript
let g = 9.8; // aceleración de la gravedad en la Tierra
```
**Tu Reto:** ¿Qué pasa si cambias el `9.8` por `25` (gravedad de Júpiter) o por `1.6` (gravedad de la Luna)? ¡Cámbialo, guarda el archivo y pruébalo!

### Misión 2: ¡Colores Locos! 🎨
**Archivo a buscar:** `css/style.css`

Abre el archivo de estilos globales y busca esto al principio:
```css
:root {
  --clr-bg: #121826;
  --clr-surface: #1f2937;
  --clr-primary: #3b82f6;
  --clr-accent: #00d4aa;
}
```
**Tu Reto:** Cambia los códigos de colores (los que empiezan con `#`). Por ejemplo, busca en Google "color picker" y elige colores que te gusten. Copia el código que te da (como `#ff0000` para rojo) y ponlo en `--clr-primary`. ¡Verás cómo cambia toda la página!

### Misión 3: ¡Nuevas Reacciones Químicas! 🧪
**Archivo a buscar:** `modules/quimica/quimica.js`

Ve a la lista de reacciones (se llama `reactions`). Verás algo así:
```javascript
{ elements: ['H', 'O'], result: 'Agua (H2O)', color: 'rgba(59, 130, 246, 0.7)' }
```
**Tu Reto:** ¡Invéntate una nueva reacción! Añade una nueva línea con tus elementos favoritos y ponle un color loco.

## 💡 Consejos de Superhacker
*   **Lee los comentarios:** Los textos que empiezan con `//` son notas para ti. ¡Te darán pistas!
*   **Guarda y actualiza:** Después de cambiar algo en el código, no olvides guardar el archivo (Ctrl+S) y recargar la página en tu navegador (F5 o el botón de girar) para ver tus cambios.
